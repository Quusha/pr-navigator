# Навигатор плана развития

Справочник по Правилам разработки и утверждения планов развития контролируемых государством АО, ТОО и государственных предприятий (приказ Заместителя Премьер-Министра – Министра национальной экономики РК от 30.04.2025 № 18).

- Структура плана по приложениям 1–32: что заполняется, где ошибаются, пункт Правил
- Календарь сроков с расчётом ближайших дат
- Чек-лист проверок увязки показателей
- Автоматическая проверка выгрузки с веб-портала реестра (.xls/.xlsx) прямо в браузере — файл никуда не отправляется
- Типовые вопросы и ответы, глоссарий

Один файл `index.html`, без сборки. Внешняя зависимость — SheetJS с cdnjs (чтение Excel) и шрифты Google Fonts.

Справочник не заменяет текст Правил: сверяйте формулировки с ИПС «Әділет».
